# portfolio

Personal site — **[kaizennnnnnnnn.github.io/portfolio](https://kaizennnnnnnnn.github.io/portfolio/)**

One `index.html`. No framework, no build step, no runtime dependency, and no
third-party request at all — the three typefaces are self-hosted next to the page.

## The idea

A blacked-out bench on which three machines are the only light source. Seven real
phone screens and one live instrument, each big, each lit, each annotated with the
specific engineering decision it proves. The page has no colour of its own: it borrows
the colour of whichever screen is currently lit, so the warm pixel world of Eren and
the cold editorial world of Outrank stop fighting and take turns lighting the bench.

The authorship disclosure is not a footnote. It is section 01, drawn as a patch bay,
and Eren and Outrank each run two leads — one into **Directed**, one into **Owned**.
You see the argument before you read a word.

## What actually runs

`§02 Murmur` has no screenshot, because the project is a Windows dictation app. So it
is the one thing on the page you can operate. The magnitude-response plot is the real
transfer function of the 4th-order Butterworth high-pass, drawn from coefficients
generated by `scipy.signal.butter(4, 100, 'highpass', fs=16000)` and evaluated in the
browser — 45 Hz lands at −27.7 dB, 1 kHz is flat. Hold the button and the same
cascaded `BiquadFilterNode` runs on your own microphone. Nothing is uploaded.

Until you press, the trace is a **synthetic demo signal**, and the page says so. On a
site whose thesis is honesty, a fake "recording" would be a strange thing to ship.

## Assets

`shots/` holds each screen twice: `<name>-461.webp` is the in-page source (461 w,
exactly half of 922, so the pixel art halves cleanly) and `<name>.webp` is the full
922 × 1858, fetched only when a plate is opened. The two tarot cards are cropped out
of `outrank-explore.webp`.

`fonts/` is self-hosted woff2. The `-latinext` files are subset to the Serbian
diacritics only — 84 KB down to 7 KB for Archivo — because the only thing this page
needs from that range is the caron in his own name.

## Running it

Serve the folder — relative paths and font loading both behave as in production:

```
python -m http.server 8000
```

`cv.pdf` is generated from `Desktop\CV\cv.html`, never authored twice:

```
chrome --headless=new --no-pdf-header-footer --print-to-pdf=cv.pdf http://localhost:8000/cv.html
```

Two A4 pages. Regenerate it whenever the CV changes — the bench bar and §07 both link it.

## Notes for future edits

Three things that are load-bearing and look like mistakes if you don't know:

- **`scroll-snap-type: mandatory` yanks any *incremental* programmatic scroll straight
  back to the nearest snap point.** The arrow keys and the drag-release glide both
  suspend snapping while they animate and restore it on the last frame. `scrollBy` and
  `scrollIntoView` with `behavior: 'smooth'` are swallowed entirely — don't reach for them.
- **The patch-bay cables are generated from measured geometry**, never hand-authored
  path data. The first attempt was authored by hand and connected nothing. They render
  *behind* the panels, so a lead running to a lower rail disappears behind the one above
  it, which is what a real patch bay does.
- **Callout dots are percentage-positioned inside the image's own aspect box.** Every one
  was verified against the rendered screenshot, not estimated. If you move one, re-check it.

`index.v1.html` is the rejected first version, kept for reference.
