Substrate — what is mine, layer by layer

The schema is mine: 37 tables, 93 row-level-security policies, 27 security-definer RPCs. I designed the access model, and I read and modified every policy written for it. The LLM integration is mine. I did not write the React or the TypeScript. I read it, I change it, I debug it, and I ship it.

Three decisions in here that nobody handed me. The prompt prefix is split at two cache breakpoints by how often each part changes — persona daily, memories the moment one is saved — so saving a memory stopped rewriting a roughly 2,900-token prefix at the 1.25× cache-write rate.

The daily spend ceiling is an integer ledger in micro-USD, written in a finally block, so a stream the user cancels halfway is still billed and the ceiling still means something.

And the multi-tenant decay sweep pages by keyset on id, not OFFSET, because the sweep mutates last_decay_at — the very column an OFFSET would have ordered on, which silently skips households once the table outgrows one page.

Substrate — where the money stops

The budget model is mine. Each tier gets a daily allowance in seconds — 60, 240, 600 — and the allowance is checked before a realtime session is ever minted, not after it ends, so an exhausted account is refused with HTTP 429 instead of running up a bill and getting reconciled later.

The quota increment happens inside a Firestore transaction, because two tabs opening a session at the same moment is not a hypothetical. The application code around it was written by coding agents I directed.

MURMUR

plate 03murmur — listening overlay · 16:10

You hold a key, you talk, and the text is in the editor before you have finished thinking the next sentence. Every line of it is mine.

A push-to-talk dictation app for Windows. Python 3.12, PySide6 on Qt6, 32 modules, 7,315 lines, written by hand.

faster-whisper small.en runs locally on the GPU. Getting there meant fixing CUDA DLL loading on Windows: the nvidia-cu12 wheels place cuBLAS and cuDNN outside the directories Windows searches, so the loader is corrected at process start. When local inference comes back empty the request falls through to Groq's whisper-large-v3-turbo — the only branch on this page drawn in rust, because it is the only path that exists conditionally.

Before the model sees anything, the audio is cleaned: 200 milliseconds off the head and 100 off the tail to kill the transient of the hotkey itself, a 4th-order Butterworth high-pass at 100 Hz, then peak normalisation to 0.8. A guard on silence, because a model handed near-silence will confidently invent a sentence. And a 282-line watcher that learns the corrections I keep making and stops making me make them.

It is not on GitHub. I am saying so here rather than leaving you to find out.
